# 🔥 FIREWALL HEIST

A neon-green, hacker-themed **cybersecurity interface prototype** built as a front-end simulation for an innovation presentation.

> **Simulation only.** This project is a visual demo, not a real authentication system or hacking tool. It does not access external systems. The demo inputs are processed locally in the browser and are not saved or sent to a server.

## ✨ Features

- Dark terminal-inspired UI with neon-green styling
- Responsive layout for desktop and mobile screens
- Fictional operator ID and fake access-key fields
- Interactive **Bypass Firewall** simulation with terminal status messages
- Reset control to replay the demonstration
- No frameworks or build tools required

## 🚀 Run locally

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Enter a made-up operator ID and a fictional access key.
4. Click **BYPASS FIREWALL** to run the simulation.
5. Click **RESET** to try it again.

## 🌐 Deploy with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`.
5. Click **Save** and wait for deployment to finish.

Once GitHub Pages is enabled, the expected site address is:

**https://26352cm012.github.io/firewall-hiest/**
